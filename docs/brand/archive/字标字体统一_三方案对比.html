P 和 oplex 字体不统一 · 三方案

所有样例的 P 都是同一份矢量路径（未改动），只换 oplex 的字体 / 颜色 / 字重。 每行右侧标出该字体的粗细比 —— 这是 P 与 oplex 是否"同族"的关键指标， P 本身是 2.9 : 1。

所有字标的 P 字高统一为 60px，字号由脚本按各字体实测的 cap height 反算， 所以是公平对比，不会因为字体度量不同而看错大小。

A1 更稳。Bodoni 的最细处比 P 还细，20pt 以下会掉笔画 —— 而字标的下限本来就是 18pt。Playfair 的 2.6 : 1 和 P 的 2.9 : 1 几乎贴合， 而且它还能顺手接管你启动页那种编辑感大标题，一个字体解决两件事。

B全画成路径

按 P 的骨架把 o / p / l / e / x 五个字母重画一遍。 这里用 Playfair 代表它的外观 —— 因为 B 做出来就该长这样。 B 和 A1 的差别不在好不好看，在归属和可控性： 路径是自己的，不依赖任何字体授权，也不会因为系统更新而变形， 而且可以按需微调（比如把 x 的收笔改得更利落）。

承认它是「图形 + 文字」的组合：P 是 mark，oplex 是名字。 只要两者看起来不是同一个东西，字体不同就不再是缺陷 —— 而是刻意。 零成本，但字标不再是一个整体。

方案视觉结果工作量长期成本风险
A1 Playfair 字体统一，粗细比 2.6 vs 2.9，几乎看不出差 打包字体 + 改一个 token 低。字体文件跟版本走 需确认 SIL OFL 授权（Playfair 是开源字体，商用免费）
A2 Bodoni 比 P 还高对比，气质更"时装杂志" 同上 低 小尺寸掉笔画，与 18pt 下限冲突
B 自绘 ≈ A1 画 5 个字母 + 反复调 kerning 中。以后改字标要改路径，不能改字号了事 画不好会比用现成字体更糟
C 拉层级 不统一，但读成"两个东西" 改颜色 / 字重，几行 零 字标失去整体性；C1 还会牺牲墨点

我推 A1。B 的产出和 A1 几乎一样，但成本高一个量级 —— 在你现在这个阶段（MVP、一个人、还有 Tab2 在做），不值得为"路径归自己"付这个价。 真到了要注册商标、做品牌手册的时候再把 A1 转成 B，那时 A1 就是 B 的稿子。
C 是"不解决问题，改成不把它当问题"。也成立，但它会让字标从一个词退回成一个组合， 你之前挑 S2 开屏方案时看重的正是「名字被拼出来」这个整体感，C 和它是冲突的。

两处渲染误差。① 真机上的 New York 在这页没法渲染，用 Times New Roman 代替 —— 两者同为过渡期衬线、粗细比接近，但字形细节不同，所以"现状"那一行看个大概即可。 ② Playfair / Bodoni 是网络字体，首次打开可能会闪一下回退字体。
选定 A1 后要做的事：把 Playfair Display Italic 700 子集化（只留 oplex 五个字母 其实就够字标用，但建议保留全字母以便标题也用），打进 bundle， 然后只改 AppTheme.Font.wordmark(size:) 一处 —— PoplexWordmarkMetrics.capPerEm 是向 UIFont 实测的，会自动跟上，其余全部不用动。
