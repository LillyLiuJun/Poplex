## 一、起因

产品负责人原话：

> 产品做完之后发现整个产品的风格和我最初设计的 icon 完全不相符。

起初的诊断是针对当时那版「斜切 Didone 橙色 P」的：字形族不一致、橙墨角色和字标相反、密度过满、小尺寸墨点退化。

**但方向在过程中变了两次**，最终跳出了字母 P。所以上述诊断只作为历史记录，不再是当前的工作前提。

## 二、硬约束

〔定〕以下每一条都是产品负责人明确要求或明确否决过的。

| # | 约束 | 说明 |
|---|---|---|
| 1 | **品牌橙 `#FF7622` 必须保留** | 不改色值、不调亮调暗、不降饱和 |
| 2 | **底色与 App 内一致** | 暖纸 `#FBF8F5`（= 卡片底）。判据是**点开 App 的那一秒不能有断层** |
| 3 | **气质：温润极简** | 安静、克制、有编辑感。桌面上应该因为「安静」被注意到，不是因为「更大声」 |
| 4 | **简单克制** | 颜色档数是硬指标。原版用了 6 档（含半透明中间色），目标 **≤ 3 档** |
| 5 | **全尺寸成立** | 1024 / 180 / 120 / 60 / 40 / 29 / 20。**29px 是否决线**，任何笔画不能断、糊、消失 |
| 6 | **深色模式变体** | 必须有。`Contents.json` 需改成 Xcode 15 的 appearances 写法 |
| 7 | **与产品内视觉不脱节** | 这是整件事的原始诉求，也是最终验收标准 |

## 三、风格基准 = 主视觉海报

〔定〕产品负责人指定那张 `English, built from your life.` 海报为风格基准（"是这种感觉的"）。从海报里提取的四条：

| 条目 | 值 | 说明 |
|---|---|---|
| **底不是平色** | 暖白 + 右上淡粉晕 + 左下更淡 | 海报的底就是这么做的，不是一块死平的色 |
| **那圈浅粉弧** | `#F8DFCD` | 右上角被裁掉的粗环，承担全部柔和感 |
| **线是暖灰不是墨** | `#BCB5AC` | **墨色在这套体系里只属于字**。非文字图形一律暖灰 |
| **橙的面积** | 5–7% | 满饱和，但极小面积。海报里橙就是这个量级 |

**两条重要更正（都是我先判错、后撤回的）：**

1. **高对比展示衬线是品牌声音，不是问题。** 我一度判定「Didone 那一路不合调性」，海报证明这条不成立 —— 展示字本身就是高对比现代衬线。错的只是图标上的**斜切**和**橙做字面**。
2. **海报里非文字的线全是浅灰。** 我前几版用墨色画线，那是画图表的手法，不是这套体系的手法 —— **这是它显硬的主要原因之一**。

## 四、内容方向

### 4.1 产品定义（直接决定图标能画什么）

〔定〕**多入口：拍照 / 录音 / 打字，拍照只是入口之一。**

推论 —— **图标不能画任何单一的输入形式**。画照片就把产品缩小成拍照翻译，画念头又漏掉拍照。唯一的不变量是**输出：一句属于你的英文表达**。

这一条否掉了「字幕」「命名」等一整类以「有一个可被拍下的对象」为前提的方案。

### 4.2 意图维度

〔定〕产品负责人认为图标应从 **Language 和 Life** 两个维度出发。

〔定〕并且明确否决了"并置两个概念"的做法 —— 对第一轮提案的评价是「和语言的关系很牵强，不够直接，和生活也没有关系」。

〔议〕由此推出的判准（供后续方案自检）：

1. **直接性** —— 外行第一反应里有没有「语言 / 英语」？不是"想一想能想到"。
2. **不可拆** —— 这个东西能不能脱离生活单独存在？能，就说明它只是语言。
3. **动作性** —— 是不是用户在产品里真正做的那件事？
4. **可缩性** —— 38 / 29px 上还剩下什么。**否决项，不是加分项。**

### 4.3 当前在做的方向

〔定〕**「两片」** —— 来源是那版橙色双片（半透明层叠）图标，产品负责人要求在它之上优化，**要简单克制**。

已做的减法（四档，见 `图标_两片_减法四档_v1.html`）：

| 档 | 内容 | 色数 |
|---|---|---|
| ① | 三片，但全部实色（去掉半透明） | 4 |
| ② | 两片，一深一浅 | 3 |
| ③ | 一片实橙 + 一片墨线空框 | 3 |
| ④ | 纯平单色，无光晕 | 2（减过头） |

〔议〕推荐 **③** —— 墨色回来了、有了对比锚点、和 App 内「墨为主橙为辅」的主次对齐，而且第一次有了意思：**一实一虚 = 左边是你已经有的，右边还空着。**

### 4.4 备选：pops

〔定〕产品负责人认可 pops 作为可用意象（"pops 这个意向你能做出来也行"）。

已出方案：一条带缺口的线 + 浮在缺口上方的橙点（见 `图标_海报材质_四版_v1.html`）。

**这条路的最强论据**：那张海报的卡片正中已经有这个图形了 —— 一条细线、中间断开、坐着一个小橙点。**图标不是新造的符号，是把主视觉里已存在的元素放大。**

〔议〕它目前处于"未被否决但未被选中"的状态，若「两片」走不通可回到这里。

## 五、明确否决项

**每一条都要写清理由 —— 否则下一个接手的人会把方向推回去。**

| 方案 | 否决理由 | 来源 |
|---|---|---|
| 斜切 Didone 橙色 P | 字形不对，不是产品的风格 | 〔定〕 |
| 空引号 / 裁切标记 | 和语言的关系牵强，和生活没关系 | 〔定〕 |
| 满幅品牌橙底（如 `sayable_icon_master.svg` 原版） | 满幅橙是「大声」，与温润极简相反 | 〔定〕 |
| 半透明多层叠加 | 橙被拆成四五档中间色。**克制的反面不是鲜艳，是层次太多** | 〔定〕要求"简单克制" |
| 白圆角卡 + 内发光（3D icon 那一套） | 和海报的平面编辑感是两种语言，38px 必糊 | 〔议〕 |
| 气泡 + 镜头等具象拼接 | 两个具象物件互相稀释，小尺寸糊，且与几百个语言 App 撞脸 | 〔议〕 |
| 折角 / 翻页 | 语言性为零，且与稍后读类 App 撞形 | 〔议〕 |
| 半满圆环（`sayable` 的几何） | 半满圆在手机上就是**进度环 / 电量**，形本身带的，调参数救不了 | 〔议〕 |
| 纯平单色两片（减法 ④） | 两片只靠中间缝分开，缝一糊就是一块橙疙瘩 | 〔议〕 |

## 六、待定项

**别让任何人（包括 AI）替你定这些。**

1. **最终形** —— 减法 ③（一实一虚）还是 ②（两片深浅）？
2. **光晕** —— 留不留、留多大。目前 ②③ 用的是半径 42%、亮度为原版一半。
3. **橙色句点** —— 那个贯穿 `Poplex.` / `your life.` / 进度条的原子，要不要在图标里出现。目前「两片」方案里它消失了。
4. **图标与字标是否同源** —— **现方向已经脱钩**：`PoplexPShape` 那条「贯穿字标 / 水印 / 开屏」的共用路径不再覆盖图标。这是真实的资产成本，需要明确接受或推翻。
5. **29 / 20px 的单独参数** —— ③ 的空框描边要从 5 加到 7 才不发虚；左右重量不等，实心片建议再收窄 2。
6. **`Contents.json` 深色 appearances 改造** —— 独立一刀，与风格选择无关。

## 九、给下一个接手者的 brief（可直接粘贴）

```
为一款 iOS 英语学习 App 设计 App 图标。

【产品】
名称：Poplex
做什么：用户用拍照 / 录音 / 打字记录自己身边的生活，AI 把这些变成属于他自己的英语表达。
用户攒下的单位叫 pop。
一句话：不是教材，就是你身边正在发生的事。
注意：输入是多形态的，图标不能画任何单一的输入方式（不要画相机、麦克风、键盘）。
唯一的不变量是输出 —— 一句属于你的英文表达。

【风格基准】
以主视觉海报为准。四条：
1. 底不是平色 —— 暖白 #FBF8F5 打底，右上角一层极淡粉晕。
2. 可用那圈浅粉弧 #F8DFCD（海报右上角被裁掉的粗环）。
3. 非文字的线用暖灰 #BCB5AC，不用墨色。墨色在这套体系里只属于字。
4. 品牌橙 #FF7622 满饱和，但只占画布 5–7%。

【硬约束】
- #FF7622 不许改。
- 颜色档数 ≤3（极淡的渐变底不计入）。
- 禁止半透明叠加产生中间色 —— 层次靠实色深浅，不靠透明度。
- 禁止 3D、内发光、玻璃质感、白圆角卡。
- 必须有深色模式变体。
- 29px 下任何笔画不能断、糊、消失。这是否决线。
- 打开 App 的那一秒不能有断层 —— 图标底色与 App 卡片底一致。

【气质】
安静、克制、有编辑感。放在一堆高饱和图标中间，
它应该因为「安静」被注意到，而不是因为「更大声」。

【已经否掉的，不要再提】
斜切的 Didone 字母 P；引号；裁切标记；满幅橙底；半透明多层；
3D 层叠；气泡 / 镜头 / 麦克风等具象拼接；折角翻页；半满圆环（像进度环）。

【交付】
SVG 路径代码，1024×1024 母版 + 小尺寸单独一版（29px 以下的参数补偿）。
浅色版 + 深色版。不要位图。
```
