图标底色 · 该怎么处理 #FF7622

我去量了 Granola 那个橄榄底：#B9C43A，HSL 65° / 饱和 54% / 明度 50%， 相对亮度 Y = 0.50，和上面那条黑线的对比度 9.9 : 1。

关键不是"把品牌色调深"或"调浅"，而是它做了两件事： ①底色明度提到中间偏亮（Y≈0.5），②对比全部交给深色线条去扛。 底不吵，字够狠。我们的 #FF7622 原色 Y 只有 0.36 且饱和拉满， 配白线对比只有 2.45:1 —— 既吵又看不清，正是你觉得别扭的地方。

✓ Granola 的解法

往深了调（中间两个）是最直觉的做法，但橙色一压暗就往棕/土去，越深越不像品牌色。
Granola 走的是反方向：底色往亮提、饱和往下收一点，然后把线换成深色。 底色变成一块"有颜色的纸"，深线在上面清清楚楚——这正好也是你 App 里"暖纸 + 墨字"的关系。

#F9AA76 是把 #FF7622 保持同一个色相 24°、饱和 100→92%、明度 57→72% 得到的。 Y = 0.502，和 Granola 的 0.500 几乎一样；配墨线 8.12:1，也贴近它的 9.9:1。 色相一度没动，所以它和品牌橙是同一个颜色的两个明度，不是新颜色。

你那屏几乎全是高饱和实色块（1688、淘宝、Pinterest、微信）。 #F9AA76 反而因为"不参与比大声"而突出——和 Granola 那块橄榄绿在你桌面上被记住是同一个原理。

05要新增的 token（只给图标用）
Token值用途
--color-brand#FF7622（不动）App 界面内一切品牌橙，维持现状
--color-icon-ground#F9AA76仅App 图标 / favicon 底色
--color-icon-stroke#2A2320图标笔画（浅底）
--color-icon-ground-dark#2A2320深色模式图标底

关键一条：图标底色不等于品牌色，它是品牌色的一个明度变体，只在图标里用。 写进 品牌色彩系统规范 时要标清楚边界，否则以后会有人把 #F9AA76 当成品牌橙用到界面里。
同理，#FEF5EF（品牌浅区块底）和它也不是一回事——那个是 L97 的极浅底，这个是 L72 的图标底。
