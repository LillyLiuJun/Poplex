# 顶部导航与 Tab2 标题区：视觉调整需求 v1

日期：2026-08-30  
状态：根据产品负责人本轮讨论整理；设计方向已明确，具体视觉数值待原生预览验收。本文不是已上线说明。

## 1. 目标与范围

降低顶部导航的视觉重量，改善两端分散、中间空置的构图；减少 Tab2 内容前重复的标题层级。保持现有页面职责、数据、入口去向和手势行为。

本轮交付：

1. Tab1 / Tab2 共用顶栏：居中的纯文字双 Tab、独立选中底纹、左侧两条细线的设置入口。
2. Tab2 已解锁首页标题区：采用此前选定的 B 方案。
3. 与上述调整相关的交互和可访问性回归验证。

不包含：更换全产品字体、调整学习卡内部排版、重做主题卡和列表、Onboarding、Settings 内容、Toast 系统、后端或数据逻辑。本文不重新定义 Tab2 的产品架构。

上位依据：[整体架构](../prd/整体架构_两个Tab与对话页_v1.md)。其中“Tab1 不动”是原 Tab2 功能重建项目的范围约束；本轮用户明确指定修改共用导航，仅涉及 Tab1 顶栏，不扩展到 Tab1 内容功能。

## 2. 依据与优先级

本轮最新文字要求优先于旧样张：

- 两个 Tab 只保留 `Today` 和 `Library`，移除太阳、书本图标。
- 两项分开，作为一组相对屏幕居中；不共用可见外层胶囊。
- 只有选中项带底纹，并且比当前 HTML v2 更轻。
- 左侧人物实心图标改为两条细线，入口功能不变。
- 其他交互保持，尤其是上滑渐变遮罩、左右滑动切换及切换效果。

参考材料：

- [HTML v2：居中文字双 Tab](../design/tab-navigation-study-v2.html)。仅用于位置、文字与独立底纹结构参考。
- [HTML v1：早期导航对照](../design/tab-navigation-study-v1.html)。历史参考，不作为最终样式要求。
- 会话中选定的 `Talk about today` B 版图：用于 Tab2 标题层级参考，不采用图片生成造成的卡片比例和字体偏差。

**重要修正：HTML v2 的实色顶栏承托不是最终需求。开发必须保留现有原生渐变遮罩，不能照搬 HTML 的不透明背景条。HTML 的选中底色也尚未通过验收，需要进一步减轻。**

## 3. 当前实现与本轮变化

| 项目 | 当前 App 代码 | 本轮目标 |
|---|---|---|
| Tab 位置 | 右侧，左侧为设置入口 | 双 Tab 整组相对屏幕居中；设置仍在左侧 |
| Tab 内容 | 两项都有图标，只有选中项显示文字 | 两项都只有文字，始终可见 |
| Tab 容器 | 共用玻璃胶囊，内部有暖纸色选中滑块及阴影 | 无可见共用外框；独立的轻底纹选中项，无选中阴影 |
| Today 滚动 | iOS 18+ 滚动超过 40pt 收字，回到 8pt 以内恢复 | 取消这项收字表现，因为已没有图标可作为入口 |
| 系统大字号 | 强制收字，只保留图标 | 不得复用此逻辑；文字入口必须存在 |
| 左侧入口 | `person.fill` 与圆形浮层 | 两条细线，降低容器视觉重量，仍打开同一个 Settings |
| 顶部遮罩 | `TopBarProgressiveMask` 渐进材质遮罩 | 保持现有配方与滚动表现 |
| Tab2 已解锁标题 | 大标题＋副标题＋`Your topics` | 仅保留减轻后的 `Talk about today` |

这里的“其他交互不变”有一个必要例外：**旧的滚动收字和大字号收字逻辑不再适用。** 移除图标后再隐藏文字会导致导航入口不可见；因此两个名称必须在滚动中保留。除此之外，不新增隐藏、缩放或收起整个顶栏的行为。

## 4. 视觉要求

### 4.1 双 Tab 的位置与分离

- 顺序固定：左 `Today`，右 `Library`；产品 UI 保持英文及当前首字母大写写法。
- 以整个屏幕的水平中线定位双 Tab 组合，不是在“设置按钮右边剩余空间”内居中。
- 两项之间有明确空隙，不放分隔竖线。
- 无包住两个 Tab 的可见背景、描边、阴影或玻璃外壳。
- 两项的点击区域保持稳定；选中变化不改变文字位置、组合宽度或页面内容的横向位置。
- 左侧设置入口不参加居中计算，不因切换 Tab 而移动。
- 当前无衬线导航字体继续使用；本轮不切换 Sahitya，也不修改内容衬线字族。

### 4.2 选中底纹

- “底纹”指均匀浅色填充，不是点阵、纹理、渐变或图案。
- 仅选中项有底纹；未选中项透明，但文字可读。
- 用轻微的中性色差，不额外加入品牌橙、绿色或其他功能色。
- 去掉选中项阴影，不用加深描边补偿底色变轻。
- 保留柔和圆角，文字周围留出均衡空间；不能做成两块厚重卡片。
- 选中状态由底纹、文字深浅共同表达；对辅助技术同时暴露选中语义。
- 在页面顶部、正文滚过顶部、照片滚过顶部三种背景下都能识别当前 Tab。

**调试起点，非已确认参数：** 当前 HTML v2 默认选中填充为近黑 5.5% 透明度。可先比较约 2.5%–3.5% 的中性浅底；最终以原生遮罩叠加后的观感和选中辨识度决定，不能直接把网页透明度当成已验收数值。若过淡，优先检查文字层级，不恢复厚阴影。

### 4.3 左侧设置入口

- 用两条细水平线替换实心人物图标；不要改成三线菜单、齿轮或新的品牌图形。
- 两条线清楚可辨、视觉轻，使用现有中性文字色体系。
- 线条长度、间隔、端点圆角在原生预览中微调，不在本轮文档中假定已确定数值。
- 视觉方向为不带厚重圆底、强描边和浮起阴影；不能只换图标，却留下原有重量不变的圆形容器。
- 保留不小于 44 × 44pt 的可点击区域；图形看起来轻，不等于缩小触控区域。
- 点按反馈保留；点击后仍展示现有 Settings sheet，不改成侧边栏、抽屉或新菜单。
- 辅助技术名称为 `Settings`，不能让读屏只念“两条线”或图标符号名。

### 4.4 Tab2 已解锁首页标题

- 保留 `Talk about today`，继续用衬线，字号与字重较当前大标题减轻。
- 删除副标题 `Built from your daily moments.`。
- 删除主题卡前重复出现的 `Your topics`。
- 保留下方 `Topics in progress` 分区标题。
- 收紧标题区总高度，让主题卡更早进入首屏；保留标题与卡片之间清楚的分组距离。
- 不改变主题卡内部字号、照片拼贴、内容、按钮、轮播结构或列表功能。
- 未解锁、空、加载、错误状态不套用已解锁文案；只验证它们在共用新顶栏下没有遮挡和布局异常。

## 5. 必须保留的交互

### 5.1 上滑渐变遮罩

- 保留当前 `TopBarProgressiveMask` 的渐进材质方案：状态栏区域保护较强，向下逐渐通透、消隐。
- 保留内容滚过顶栏背后的连续效果，不替换为整块不透明暖纸背景，不改成硬切边。
- 本轮不擅自修改材质、渐变节点、透明度、覆盖高度或安全区处理。
- 如布局变化确实需要调整覆盖高度，先展示与现有滚动效果的对照，说明原因，再确认该额外改动。
- 区分两层：**选中底纹减轻**不代表**整个导航遮罩减轻或移除**。

### 5.2 点击与左右滑动切换

- 点 `Today` 进入 Tab1，点 `Library` 进入 Tab2；不增加中间步骤。
- 保留现有方向：Tab1 左滑到 Tab2，Tab2 右滑到 Tab1。
- 保留水平意图判定和触发阈值，不因视觉改造修改手势灵敏度。
- 保留现有切换动画的节奏；选中反馈随切换更新。可以让轻底纹沿用当前移动反馈，但不能因此恢复共用外框或推动文字移动。
- 不新增整页左右推屏、弹跳、缩放等不同于当前实现的转场。
- 保留垂直滚动／下拉刷新与水平切换的区分，垂直操作不误切 Tab。
- 保留 Tab2 横向轮播区域的手势排除，浏览轮播不触发全页 Tab 切换。
- 若删除侧滑操作已展开，保留先收起操作而不是直接切 Tab 的保护。
- 详情页中保留现有导航与切换限制，不越过详情直接切走。

### 5.3 页面生命周期与其他入口

- 不因切换而销毁、重建两个 Tab，不丢失 Tab1 未发送的输入、图片、历史和现有滚动状态。
- 切入 Library 的刷新、列表重置等行为按当前代码保留；不把它们统一改成“全部保留”或“全部归顶”。
- 设置 sheet 的展示、关闭和返回路径不变。
- Tab2 详情时顶栏的隐藏行为、全屏图片预览覆盖顶栏的行为不变。
- 底部输入栏、键盘避让、下拉刷新、加载与错误反馈不在本轮重做。

## 6. 可访问性与适配

- 两个 Tab 保留明确的名称和选中状态，设置入口暴露正确名称。
- 字体继续通过 `AppTheme.Font` 使用系统文字样式，支持 Dynamic Type。
- 不得沿用“大字号隐藏文字、留下图标”的旧降级方式；本方案已无图标。
- 默认字号在窄屏仍应居中，且不与左侧入口重叠。
- 极大字号空间不足时，优先保证名称完整、可点击、不裁切；必要时采用增加顶栏高度的自适应排布，并单独提供验收截图，不通过隐藏名称或强行缩小字体解决。
- 尊重系统减少动态效果设置，确保无动画时仍能清楚辨认选中态。

## 7. 开发边界与参考代码

以下是核对入口，不代表要求重写这些模块：

| 文件 | 相关职责 |
|---|---|
| `AIEnglishApp/Navigation/TopTabSelector.swift` | 双 Tab 展示、选中态、当前收字与选中动画 |
| `AIEnglishApp/Navigation/RootTabContainer.swift` | 居中布局、设置入口、左右切换、生命周期、顶栏高度 |
| `AIEnglishApp/Components/WarmGlassBar.swift` | 顶部渐变遮罩；本轮保留 |
| `AIEnglishApp/Today/TodayView.swift` | 旧滚动收字的驱动，内容与其他滚动逻辑不变 |
| `AIEnglishApp/Mine/MineView.swift` | 已解锁状态标题区与顶栏避让 |
| `AIEnglishApp/Theme/Theme.swift` | 复用或集中定义必要的样式参数 |

- 先复用已有字体、颜色、间距与动效参数，确需新增时集中定义；不在页面散落视觉常量。
- 不直接改共用 `pageBg`、全局阴影或所有浮层材质来减轻这一个选中底纹，避免影响其他页面。
- 左侧按钮作为独立可复用组件实现，结构／行为与视觉样式分开。
- 仅清理已因纯文字导航而失效的收字连接，不借机重构页面加载或手势系统。

## 8. 验收清单

| 场景 | 通过标准 |
|---|---|
| Today / Library 初始状态 | 两个名称都可见、无太阳与书本图标、只有当前项有浅底纹 |
| 导航结构 | 两项有间隔、无共用外框；整组相对屏幕居中 |
| 点击切换 | 页面与选中状态一致，文字位置和组合宽度不跳动 |
| 左侧入口 | 两条细线，点击区域充足，仍打开同一个 Settings sheet |
| Today 上滑与回顶 | 文字始终保留；原渐变遮罩及内容穿过效果保持 |
| Library 照片／文字滚到顶部 | 遮罩保持原效果；选中状态仍可辨认，无新实色横条 |
| 全页左右滑动 | 方向、阈值与当前切换节奏保持 |
| 轮播、下拉刷新、删除侧滑、详情页 | 不误触发全页切换，既有保护保持 |
| Tab2 已解锁 | 仅保留减轻后的 `Talk about today`；`Topics in progress` 不丢失 |
| Tab2 其他状态 | 空／未解锁／加载／错误状态没有遮挡和额外空白异常 |
| 窄屏与大字号 | 名称不消失、不裁切，设置入口不与双 Tab 重叠 |
| 减少动态效果与读屏 | 入口名称、选中态与操作仍完整可用 |

交付时提供 Today / Library 初始与滚动状态截图，以及点击／左右滑动切换的短录屏。至少覆盖小屏与常用屏宽，并检查放大字号；HTML 不能替代原生遮罩和手势验收。

本轮当前仅产出此需求文档，尚未开发、未执行 App 测试。后续实现稳定后，对受影响的状态和手势判定做必要回归验证，报告结果；按项目工作节奏，验收通过后再进入下一批视觉调整。
