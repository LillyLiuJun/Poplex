p — 这次是画的，不是拼的

你说得对。之前那个 p 是一个矩形 + 一个椭圆 + 两条横杠叠出来的， 零件之间是硬碰硬的直角接缝，所以怎么调都僵。

这三个是单条闭合轮廓线画的——从起笔衬线出发，绕过碗，回到降部的脚，一路都是贝塞尔曲线， 中间没有任何一处直角。差别在三个地方：衬线和竖干之间有弧形过渡（bracket）、 碗从竖干里"长"出来而不是贴上去、圆的部分微微超出基线和 x 高（overshoot）， 这样眼睛才觉得它和方的部分一样高。

把碗的应力轴倾斜 12°——最薄的两点从"正上 / 正下"挪到"右上 / 左下"， 起笔衬线也改成斜切。这是宽头笔真实运笔留下的痕迹，所以它是三个里最不像"矢量图"的一个。 代价：斜轴让它在方形图标里更难摆平，需要额外微调；而且它气质偏"人文"， 和你界面那种冷静的现代衬线稍微不是一路。

橙点还在，但退到了右上角外侧——因为轮廓变复杂了，点再贴近碗肩就开始打架。 它现在是一个独立的呼吸位，不参与字形。

三个都是同一套骨架（竖干宽 15、x 高 62、降部 26、碗右伸到 100）， 只有粗细分布和过渡方式不同，所以你选哪个，之前定的尺寸规格都不用重算。
