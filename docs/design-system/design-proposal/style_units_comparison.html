Design System Insight

UI 风格的最小单元：物理材质契约对比

控制变量实验：每个容器内的内容与骨架完全相同（1个标签 + 1个标题 + 1段两行释义 + 1个状态 + 1个按钮）。
风格的诞生不依赖任何业务插图或花哨修饰，仅由 底色底温 (Undertone)、边缘曲率 (Radius & Border)、光影深度 (Light & Elevation) 三者咬合而成。

1. 为什么骨架完全相同？

如果不同卡片放了不同的按钮、不同的字数、不同的图标，我们就会被“内容差异”所误导。只有完全相同的骨骼，才能证明：风格不是画出来的，是物理材质属性赋予的。

2. 为什么圆角是关键分水岭？

0px 导向传统印刷与现代建筑的严肃；8px 是桌面效率与紧凑逻辑的标准；12px+粗黑 是波普玩具感；20px+连续曲率 则是移动人机工程中的亲和温润。

3. 为什么“光”决定了世界观？

Linear 的内微光让你感觉像隔着强化玻璃操作精密机密；纸质杂志把光完全吸掉；新野兽派用无虚化的黑块打破现实；暖极简的底部微光则像台灯下的一隅桌面。
