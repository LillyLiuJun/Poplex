## 一、基准色拆解与前置约定声明

**#FF7622 → RGB(255, 118, 34)**

HSL 拆解过程：max=255/255=1.0，min=34/255=0.1333，Δ=0.8667；
L=(1.0+0.1333)/2=**56.7%**；S=Δ/(1−|2L−1|)=0.8667/0.8667=**100%**；
H=60°×((G′−B′)/Δ)=60°×(0.4627−0.1333)/0.8667=**22.8°** → **hsl(23, 100%, 57%)**

相对亮度拆解：R线性=1.000000，G线性=((0.4627+0.055)/1.055)^2.4=0.181164，B线性=0.015996；
Y = 0.2126×1.000000 + 0.7152×0.181164 + 0.0722×0.015996 = **0.343324**

| 对比对象 | 实测对比度 | 说明 |
|---|---|---|
| 对 #FFFFFF | **2.67:1** | 低于 4.5:1，属第〇节已知设计约定，按色彩角色分层处理，不作为流程阻断 |
| 对 #000000 | **7.87:1** | 达标黑底文字 |

**处理声明**：500 阶仅作填充色；白底文字与链接一律使用 700 阶（实测 5.24:1）；唯一豁免为单屏唯一主 CTA 大按钮（500 底 + 白字，≥17px 粗体），详见第七节豁免清单。

## 八、色彩使用约束规则（强制）

1. 所有 500 阶（含主色、功能色）为填充阶，一律不得承载白底文字语义；白底文字/链接固定走各自 700 阶。
2. `--color-brand-fill`（orange-500）禁止用于任何 <17px 文字；唯一豁免见第 6.6 节，且不得扩散。
3. 警告黄任何阶禁止与白字组合；黄 500 底文字强制 `--color-warning-text-on-fill`。
4. 辅助青禁止大面积使用、禁止表达成功/警告/错误/信息任何功能语义。
5. 中性灰每阶仅一个用途归属（见第五节表），跨用途取色视为违规。
6. 禁用态一律用 alpha token（`--alpha-brand-disabled` / `--alpha-text-disabled`），不新增实色阶。
7. orange-500 与 blue/teal 400–600 阶禁止无中性隔离的大面积直接拼贴。
8. 语义层只引用原子变量，业务代码只引用语义变量，禁止直写 HEX。
