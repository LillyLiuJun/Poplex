# 品牌色彩系统规范 v2 · 暖纸灰修订（基准色 #FF7622 不变）

> 本文件是《品牌色彩系统规范-FF7622》的 **v2 修订**，仅修订**第五节 中性灰度体系**及其下游引用。
> 主色、辅助色、四大功能色、alpha token、豁免清单**全部未改动**。
> 全部新色值由代码按「保相对亮度、提饱和度」反推生成，对比度为 WCAG 2.x 相对亮度精确计算值。

---

## 〇、修订摘要（Changelog）

| # | 变更 | 原因 |
|---|---|---|
| 1 | gray 50/100/200/300 四阶**重新生成**：H 25–30°，饱和度 3–8% → **14–40%** | v1 宣称「有色暖灰 H=23°」，但浅阶饱和度被 ≤6% 上限压死，在 94–97% 明度下色相人眼不可辨，页面底色实际渲染为冷中性灰——**设计意图在数学上未兑现** |
| 2 | 深阶 gray 400–900 **保持不变** | 深阶 S=7–10% 在其明度区间已可感知暖棕，且全部文字色对比度已验证，不动 |
| 3 | 新浅阶**逐阶锁定原相对亮度 Y**（误差 ≤0.002） | 保证 v1 第六节全部对比度结论继续成立，修订不引发任何重验失败 |
| 4 | 第五节约束「50–300 阶 S≤6%」**废止**，改为「50–300 阶 S≤40% 且 H∈[24°,30°]」 | 旧上限是「暖灰不可感知」的直接原因 |
| 5 | gray-300 用途描述不变（装饰性边框），但提醒：新 300 阶暖度上升后仍禁作输入框功能边框 | 功能边框唯一色仍是 gray-500 |
| 6 | **新增语义 token `--color-bg-elevated: #FFFFFF`**：卡片/浮层 elevated 亮面 | v2 暖纸落地后发现明度结构塌缩：页面/卡片/气泡三层全在 24–30° 暖域且 ΔY 仅 0.064，无亮面承载内容，界面「没有呼吸感」。引入纯白 elevated 面重建明度节奏（见 §六） |

**未变更声明**：`--color-bg-page` 仍映射 gray-100、`--color-bg-card` 仍映射 gray-50，语义层零改动；orange-50 `#FEF5EF` 仍是「品牌浅区块底」，不升格为页面底色（见 §三 边界说明）。

## 一、问题诊断（v1 缺陷）

v1 第五节饱和度设计值：50–300 阶 S=6/5/5/4%。在 L=87–97% 的明度区间，该饱和度产生的色度差（chroma）低于人眼可辨阈值：

| 阶 | v1 HEX | v1 实测 HSL（8bit 反推） | 实际观感 |
|---|---|---|---|
| 50 | `#F9F8F8` | hsl(0, 8%, 97%) | 中性灰 |
| 100 | `#F1F1F0` | hsl(60, 3%, 94%) | 中性灰（甚至偏黄绿方向抖动） |
| 200 | `#E1DFDD` | hsl(30, 6%, 87%) | 中性灰 |
| 300 | `#BFBBB9` | hsl(20, 4%, 74%) | 中性灰 |

即：v1 的「暖」全部集中在 400–900 深阶（文字/边框，屏幕面积 <5%），而占屏幕 80%+ 的浅阶承载层是冷的。**页面气质的冷暖由浅阶决定，v1 在错误的色阶上分配了色温。**

## 二、修订后第五节：中性灰度体系（暖纸灰）

构造方法：浅阶（50–300）固定 H∈[24°,30°]（主色 22.8° 邻域，微偏黄防发粉），饱和度按「浅阶高、深阶低」重新分配——浅阶需要高饱和度才能在极浅明度下被感知，深阶保持 v1 原值。每阶相对亮度 Y 与 v1 锁定一致（误差 ≤0.002），**全部下游对比度结论继承有效**。

| 阶 | HEX（v2 新） | HSL | 相对亮度 Y | v1 HEX | Y 差 | 适用场景（不变） |
|---|---|---|---|---|---|---|
| 50 | `#FBF8F5` | hsl(30, 40%, 97%) | 0.942 | `#F9F8F8` | +0.001 | **卡片/容器背景**（唯一用途） |
| 100 | `#F5F0EC` | hsl(28, 32%, 94%) | 0.878 | `#F1F1F0` | −0.001 | **页面底色**（唯一用途） |
| 200 | `#E6DED8` | hsl(26, 22%, 87%) | 0.740 | `#E1DFDD` | 0.000 | **分割线**（唯一用途） |
| 300 | `#C5BAB2` | hsl(24, 14%, 74%) | 0.502 | `#BFBBB9` | +0.001 | **装饰性边框/禁用态背景** |
| 400 | `#948C86`（不变） | hsl(26, 6%, 55%) | — | 同 | 0 | **占位符**（收窄用途见排印 §6.3） |
| 500 | `#80766F`（不变） | hsl(25, 7%, 47%) | — | 同 | 0 | **输入框功能边框、功能性图标** |
| 600 | `#726761`（不变） | hsl(21, 8%, 41%) | — | 同 | 0 | **辅助文字** |
| 700 | `#645953`（不变） | hsl(21, 9%, 36%) | — | 同 | 0 | **次级标题/文字强调** |
| 800 | `#554B45`（不变） | hsl(23, 10%, 30%) | — | 同 | 0 | **正文** |
| 900 | `#3A332F`（不变） | hsl(22, 10%, 21%) | — | 同 | 0 | **标题** |

饱和度分配逻辑（新）：**40 / 32 / 22 / 14**（浅→深递减）接 v1 的 **6 / 7 / 8 / 9 / 10 / 10**（400→900）。浅阶高饱和补感知、深阶低饱和防文字发棕，色相在 22–30° 窄带内，全阶暖向一致、无脏灰。

## 三、与 orange-50 的边界（防止误用）

v2 页面底色变暖后，`orange-50 #FEF5EF`（hsl(24, 88%, 97%)）的角色**不升格**：

| 色 | 角色 | 区别 |
|---|---|---|
| gray-100 `#F5F0EC` | 全局页面底色 | 暖**纸灰**，中性承载层，任何内容可置于其上 |
| orange-50 `#FEF5EF` | 品牌浅区块底 | 暖**橙**，品牌语义层，仅用于品牌区块/hover 浅底，饱和度 88% ≫ 页面底 32% |

两者明度接近但饱和度差 2.75 倍，视觉上「页面是纸、区块是橙」的层级仍然成立。禁止用 orange-50 替代 gray-100 铺全局（品牌色大面积铺设会破坏 §六.3 视觉权重层级）。

## 四、对比度复验（v2 新底 × 不变文字色，精确计算）

| 组合 | v2 实测 | v1 实测 | 达标线 | 判定 |
|---|---|---|---|---|
| gray-900 标题 / gray-50 卡片 | **11.71:1** | 11.69 | ≥7.0 | ✅ |
| gray-800 正文 / gray-50 卡片 | **8.01:1** | 7.99 | ≥7.0 | ✅ |
| gray-800 正文 / gray-100 页面 | **7.49:1** | 7.50 | ≥7.0 | ✅ |
| gray-700 次级标题 / gray-50 | **6.41:1** | 6.40 | ≥4.5 | ✅ |
| gray-600 辅助 / gray-50 卡片 | **5.18:1** | 5.17 | ≥4.5 | ✅ |
| gray-600 辅助 / gray-100 页面 | **4.85:1** | 4.85 | ≥4.5 | ✅ |
| orange-700 品牌文字 / gray-100 页面 | **4.63:1** | 4.64 | ≥4.5 | ✅（余量 +0.13） |
| orange-700 高亮词 / gray-50 卡片 | **4.96:1** | 4.95 | ≥4.5 | ✅ |
| 底色斑马分离 ΔY(50−100) | **0.064** | 0.062 | — | ✅ 不劣化 |

全部偏移 ≤0.02，**v1 第六节总表其余条目（功能色、alpha、非文本、互补校验）不受影响，无需重跑**。

唯一需要持续盯防的项：`orange-700 / gray-100` 余量 +0.13，属薄余量组合。规则：**禁止再在 gray-100 页面底上使用比 orange-700 更浅的品牌文字阶**（v1 本就禁止，此处只是余量提示）。

## 六、新增语义 token：`--color-bg-elevated`（v2.1）

```css
[data-theme="light"], :root {
  --color-bg-elevated: #FFFFFF;  /* 卡片/浮层 elevated 亮面 */
}
```

**引入理由（明度节奏诊断）**：v2 暖纸灰落地后，三层结构为 页面底 Y=0.878 / 卡片 Y=0.942 / 用户气泡（orange-100）Y≈0.87——三层同处 24–30° 暖域、最大 ΔY 仅 0.064，且无纯亮面。冷暖层级对了，但**明度节奏塌缩**，界面缺乏呼吸感。

**角色定义与约束**：

| 项 | 规则 |
|---|---|
| 用途 | **内容承载卡片、浮层、输入框** 的 elevated 亮面（唯一用途） |
| 层级关系 | `--color-bg-elevated`（Y=1.000）＞ `--color-bg-card` gray-50（Y=0.942）＞ `--color-bg-page` gray-100（Y=0.878） |
| 与 gray-50 的分工 | **gray-50 降级为次级容器/嵌套容器底**（如卡片内的分区块、顶栏胶囊）；主内容卡片一律 elevated 白 |
| 明度节奏 | elevated↔page ΔY=0.122（≥0.10 呼吸线）；此时卡片描边可保留 1px gray-300 或省略，不再承担分层主责 |
| 对比度继承 | 全部文字色在白色输入框场景已验证（§六.1：gray-400 占位 3.30:1 为最低组合，余下均 ≥4.5:1），无需重跑 |
| 禁令 | 禁作页面底色（会抹掉暖纸层）；禁与 gray-50 相邻嵌套两层以上（明度差 0.058 不足以区分三级） |

**修订后的表面层级总表**：

| 层级 | token | 值 | Y | 用途 |
|---|---|---|---|---|
| L0 页面 | `--color-bg-page` | gray-100 `#F5F0EC` | 0.878 | 全局页面底 |
| L1 次级容器 | `--color-bg-card` | gray-50 `#FBF8F5` | 0.942 | 卡片内分区、顶栏胶囊、次级嵌套 |
| L2 主内容卡片 | `--color-bg-elevated` | `#FFFFFF` | 1.000 | 内容卡片、浮层、输入框 |
