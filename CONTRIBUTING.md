# Contributing

Thanks for taking an interest in Poplex.

## This project does not accept code contributions

Poplex is source-available under the
[PolyForm Noncommercial License 1.0.0](LICENSE) and is developed in a private
repository; this repository is a published snapshot of it. For that reason:

- **Pull requests are not accepted** and will be closed without review.
- **Issues are welcome.** A good bug report or idea can end up in a later release,
  but there is no promise of a timeline.

If you fix something in your own copy, that is yours to keep under the license.

## Filing an issue

Please include:

- what you expected and what happened instead;
- steps to reproduce, and the iOS version and device (or simulator) you used;
- for backend problems, the relevant Edge Function name and any error text
  (**remove keys, tokens, URLs of your project and other secrets**).

Please search existing issues first.

## Security

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).

and third-party materials keep their own terms.
