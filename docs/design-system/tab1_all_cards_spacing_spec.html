Tab1 卡片全形态微观间距规范全景图解

严格基于本地代码（AIEnglishApp 源码及 DesignLab 定稿参数），直观展现 Word、Sentence、Passage 全部三大类卡片、9 种细分形态 中每一处物理点间距与设计逻辑。

一、Word 词条卡（3 种形态）
单词 → 音标/词性同行自适应 → 释义 → Examples → Note · 四周内边距 16pt
Word
形态 1 · 音标词性同行基线对齐
↕ 16pt 类型标 → 单词标题
set up
↕ 4pt 单词 → 音标/词性组
/ˌset ˈʌp/ v. / phrase ⇥ 8pt 同行间距
↕ 8pt 音标/词性组 → 释义
建立；安排，组织；准备
↕ 16pt 主词条信息组 → Examples 区块
EXAMPLES
↕ 8pt Examples小标 → 第一条例句
Let's set up a quick sync tomorrow.
↕ 4pt 目标语 → 中文翻译
我们明天安排一次快速同步。
↕ 12pt 两组例句之间
She helped set up the new branch office.
↕ 4pt 目标语 → 中文翻译
她协助筹建了新的分公司。
↕ 16pt Examples区块 → Note 区块
NOTE
↕ 4pt Note小标 → 正文说明
口语中极其高频，既可表示搭建系统、安排会议，也可指给某人挖坑（set someone up）。
Word
形态 2 · 窄屏自适应分行折叠
↕ 16pt 类型标 → 单词大标
incomprehensibility
↕ 4pt 单词 → 音标
/ɪnˌkɑːmprɪˌhensəˈbɪləti/
↕ 4pt 窄屏自适应：词性整组折行到音标正下方
n. / uncountable
↕ 8pt 折行组 → 释义
无法理解；不可思议
Word
形态 3 · 无音标/无词性
↕ 16pt 类型标 → 单词大标
touch base
↕ 8pt 无音标词性时：单词直接 → 释义（绝不留空行）
简短交流，互通情况
二、Sentence 句子卡（4 种形态）
修正态 (Polish) · 表达态 (Express) · 无修正带Note · 极简理解态 (4pt vs 8pt)
Sentence
形态 4 · 修正态 (Polish)
↕ 16pt 类型标 → 原句
I am very sleep today, because too much meetings.
↕ 4pt 原句 → 原句译文
我今天很困，因为会议太多了。
↕ 16pt 原句组 → Polish 润色区块
POLISH
↕ 4pt Polish小标 → 修正句主角
I’m very sleepy today because of too many meetings.
↕ 16pt 修正句 → Note 说明区块
NOTE
↕ 4pt Note小标 → 说明正文
形容身体发困用 sleepy（形容词）；会议是可数名词复数，用 too many 修饰。
Sentence
形态 5 · 表达态 (Express)
↕ 16pt 类型标 → 母语输入提示
我们下周一再把最终方案敲定下来吧。
↕ 8pt 母语提示 (灰) → 目标语表达主角 (深色)
Let’s finalize the proposal next Monday.
Sentence
形态 6 · 极简理解态 (无 Note/无 Polish)
↕ 16pt 类型标 → 目标语原句
I’m heading out for lunch now, back in thirty minutes.
↕ 8pt (推荐) 目标语 → 中文翻译 (对比 4pt 更加舒展沉稳)
我现在出去吃午饭，半小时后回来。
三、Passage 篇章长文卡（2 种形态）
定案：彻底移除细横线 · 句对间 16pt 纯留白自然分隔 · 展开收起 12pt
Passage
形态 7 · 收起折叠态 (定案：无横线)
↕ 16pt 类型标 → 正文首句
Coffee culture in Melbourne is not just about caffeine; it's a daily ritual of connection.
↕ 4pt 目标语分句 → 中文翻译
墨尔本的咖啡文化不仅关乎咖啡因，更是一种建立人际连结的日常仪式。
↕ 16pt 句对与句对之间纯留白分隔 (无横线)
Locals take immense pride in their independent cafes tucked away in historic laneways.
↕ 4pt 目标语分句 → 中文翻译
当地人对自己藏在历史小巷里的独立咖啡馆感到无比自豪。
↕ 12pt 正文尾句 → 展开入口 (Expand full text)

📐 Tab1 间距心智法则速查总表
数值 设计法则 覆盖场景
4pt 微观紧凑绑定律 单词→音标/词性、例句目标语→翻译、Passage分句双语、Sentence修正态原句→译文、Polish标/Note标→正文
8pt 核心层级转换律 音标/词性组→释义、无音标时单词→释义、Examples小标→首条例句、Sentence表达态母语→目标语、极简理解态舒展版、[外部] 图片→文字
12pt 同域适度呼吸律 两组例句之间、Passage正文尾句→展开/收起按钮、[外部] 用户输入气泡→AI卡片结果
16pt 主模块边界划分律 卡片四周固定内边距 (paddingCard)、类型标→首项内容、主信息组→Examples、前方内容→Note、Passage句对间纯留白、[外部] 日期→首条输入
28pt 单元对话呼吸律 [外部] 每次 AI 回复或发送失败行 → 下一次用户输入气泡
32pt 跨天时间宏观律 [外部] 上一次卡片/失败行 → 跨天日期胶囊 (首个日期不加)
