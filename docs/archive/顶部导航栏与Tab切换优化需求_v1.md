# 顶部导航栏与 Tab 切换优化需求 v1

> 状态：已确认，待实现  
> 日期：2026-08-30  
> 范围：仅调整应用主界面的顶部导航视觉；不改变 Tab 结构、页面内容或已有手势逻辑。

## 1. 目标

把现在带图标、共用胶囊外框的 Tab 切换器，改成更安静的文字导航：`Today` 与 `Library` 独立并列、整体居中。选中项用很浅的底纹标示，而不是厚重的胶囊或阴影。

左上角的个人头像图标视觉重量偏高，换成一个轻量的双横线菜单图标；它仍然打开现有 Settings。

## 2. 顶栏最终结构

```
[ 双横线菜单 ]              Today     Library
                                  └─ 选中项带很浅的圆角底纹
```

- `Today` 与 `Library` **只显示文字，不显示 sun / books 图标**。
- 两项是两个独立的可点目标：中间留出明确空隙；不使用共同的外层胶囊、边框或阴影。
- 两项作为一个整体，按屏幕水平中心对齐；不再靠右排列。
- 文字始终显示。滚动页面时，不能隐藏文字、压缩为图标或改变两项的位置。
- 触控区域保持至少 44 × 44 pt；文字居中，点击任一项切换到对应页面。
- 选中项：使用暖中性、低对比度的浅底纹，圆角约 20 pt；不加投影、不加描边、不使用高饱和品牌色。
- 未选中项：透明背景，使用次级文字色。
- 选中项文字使用主文字色；两个状态都保持同一字号与字重，避免切换时文字跳动。

### 底纹强度

底纹的目标是“能辨认当前页面，但不抢内容注意力”。建议从当前预览的较浅档开始：黑/深棕基色约 5% 不透明度（例如 `rgba(33, 24, 17, 0.055)`），而不是较深的约 9% 档。最终以真机纸灰背景下的观感校准；验收时若第一眼先看到的是底纹，说明仍然过重。

## 3. 左侧入口

- 保留左上角入口的位置、44 × 44 pt 可点击范围、按压反馈与打开 Settings 的行为。
- 将当前实心 person 图标替换为**无圆圈、无填充的双横线菜单图标**：两根圆头横线，线条细而克制，长度可略有不同。
- 图标本身不使用实心块或人物轮廓；颜色沿用次级文字色。
- 按钮现有的轻量浮层/背景可以保留。本需求只降低内部图标的视觉重量，不把它改成新的导航功能。
- 无障碍名称保持为 `Open Settings`，不能因为图标替换而变成“two lines”等图形描述。

## 4. Library 内容区顶部标题（已确认 B 版）

这里的“顶部标题”是进入 `Library` 后、首张主题卡上方的内容区标题；它不是全局顶栏里的 `Today / Library` 切换器。

- 保留 `Talk about today` 作为内容区唯一的页标题，沿用目前减轻后的衬线标题风格、左对齐轴和暖深色文字。
- 移除标题下方的副标题 `Built from your daily moments.`，不以其他说明文字替代。
- 移除 `Your topics` 分区标题。
- 标题之后直接进入首张主题卡／横向主题卡区域；不因为删去副标题和分区标题留下突兀的大段空白。
- `Topics in progress` 仍保留，继续作为下方进行中主题列表的标题；它与 `Talk about today` 的职责不同，不在本次移除范围内。
- 不改变主题卡的内容、横向轮播、`Start talking` 入口、卡片数据或解锁/加载/空状态逻辑。

这样首屏的阅读顺序为：`Talk about today` → 主题卡 → `Topics in progress` → 进行中主题。页面减少重复的栏目命名，让第一张卡更早进入视野。

## 5. 必须保持不变的交互

本次只改视觉与文字呈现，以下行为不得回归：

1. **顶部渐进遮罩**：内容继续在顶栏下方滚动，顶部现有的渐进模糊/淡出遮罩保留；不能变成一整条明显的实色或材质栏。
2. **左右切换**：从 `Today` 左滑进入 `Library`，从 `Library` 右滑返回 `Today` 的现有阈值、动画和边界规则保持不变。
3. **横向内容优先**：Tab 2 内横向卡片轮播继续优先处理自身手势，不能被根级左右切换手势抢走。
4. **下拉刷新**：垂直下拉刷新与珍珠动效不受影响；垂直拖动不能误触发页面切换。
5. **切换反馈**：点击文字或完成左右滑动后，仍使用现有平滑的 Tab 切换动画；不新增页面重载、数据刷新或导航层级变化。
6. **详情页规则**：Tab 2 进入详情页时，现有隐藏顶栏及禁止右滑返回 Tab 1 的规则保持不变。
7. **无障碍字号**：在较大辅助字号下，导航仍需完整显示 `Today` 与 `Library`，不得退化为图标、截断文字或挤出屏幕。

## 6. 实现边界

- 涉及组件：`AIEnglishApp/Navigation/TopTabSelector.swift` 与 `AIEnglishApp/Navigation/RootTabContainer.swift`。
- Library 内容区标题涉及 `AIEnglishApp/Mine/MineView.swift` 的已解锁首页；标题、间距和颜色继续从 `AppTheme` token 层取值。
- 颜色、字号、间距、圆角和动画必须继续从 `AppTheme` token 层取值；新增双横线图标也应封装为可复用的小组件，不能散落在页面中手写。
- 不修改 Tab 1、Tab 2 内容页、数据请求、Settings 页面或后端。
- `Today` / `Library` 是产品 UI 英文文案，保持不变。
