Onboarding 第一屏 · 在方案 2 上「色块减重」

保留你喜欢的底部色块锚定感，但两处改动：① 文案全部回到上方纸面（深色编辑字），色块里不再放句子；② 色块瘦身减重，只托住 CTA。三种减重手法并排——浅色托盘 / 渐隐橙光 / 窄色带。

A · 浅色托盘 ★推荐

Pale Shelf

色块降为浅橘（primary200），高度收窄，只托 CTA。分量来自"托盘 + 柔阴影"，橙的punch集中在按钮上。最克制、最贴品牌，减重最彻底。

B · 渐隐橙光

Faded Sunrise

橙色从底部往上渐隐、无硬边，像暖光升起。因为没有"硬矩形"所以最轻盈，仍有明确橙色重心。CTA 用深色更稳。介于色块与光晕之间。

C · 窄色带

Slim Band

保留原来的饱和橙，但色块大幅收窄成"只包住按钮"的窄带。占比小了就轻了，橙色浓度还在。品牌最外放，但饱和橙仍是三者里最"响"的。
