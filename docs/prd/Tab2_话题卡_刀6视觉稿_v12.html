每个胶囊只装一件事，边界由形体给出，不再需要 ·。 次数消失后，一行里剩下的全是名词—— 这一列现在读起来是「你做过这些事」，而不是一段统计。

胶囊解决的三件事

不是换个装饰，是三个 v11 没解决干净的问题一起消失了。

① 边界

v11 用 · 分隔，可 Eating at home 里本来就有空格—— 眼睛得先断句才知道哪到哪是一个活动。 胶囊的边界是看出来的，不是读出来的。

② 可点性

活动本来就该能点进去看那几张照片。 文字流里没有一个明确的可点区域，胶囊天然就是。 这一版没做点击，但形体先把路留出来了。

③ 层级

v11 里活动名 16px 衬线是全行最大，可它旁边贴着 11px 上标数字， 大小差了 5px 的两个东西挨在一起，谁也不安生。 次数拿掉后，行里只剩一个字号。

代价要说清楚：Sharing thoughts 发生过 12 次、 Texting 发生过 2 次，在卡片上现在看起来一样重。 次数仍然决定顺序（第一个胶囊就是最常发生的）， 但"多"和"少"不再能一眼读出。

我认为这笔交易划算：次数是系统的观察，活动名是用户的生活。 卡片这么小，先保后者。真要让重复可见， 以后可以让胶囊的底色深浅跟着次数走——不占任何宽度，也不多一个数字。

两行，装得下几个就几个

规则和 v11 完全一致，只是计量单位从"行内字符"变成"胶囊宽度"。

规则定义
候选后端每类返回最多 5 条，已按 occurrence_count 降序排好，客户端原序取用，不重排
显示两行排得下几个就几个。名字短时 4–5 个，名字长时可能只有 1–2 个
+N moreactivity_count 减实际显示数。作为最后一个"无底色胶囊"跟在末尾，N = 0 时不渲染
让位放不下就少显示一个胶囊，绝不截断活动名。少一个，N 自动加一
高度两行是固定高度：只有 1 个胶囊也占两行的高。卡高与行高恒定
次数不渲染。后端照常返回 occurrence_count，客户端只用它排序

同一个形体换中性色。颜色在做事，形体不变。

文案三档：Added N times today（N ≥ 2）/ Added something today（N = 1）/ Nothing new in X（N = 0）。

理由行移到图上之后，它就不能再用浅底胶囊了——照片深浅不可控，浅底会在深色照片上炸成一块白斑。 所以图上版沿用类别标签那套半透明深色底，暖橙只留给那个点和字色 （#FF8A4C 点 / #FFE4D2 字，在深色底上才够亮）。 形体、位置、两种状态的规矩都不变。

后端配套一条小修：new_material_count 补上 AND lo.source_type = 'material'， 让"次数"只数用户自己放进来的东西——对话上线那天，这个数字不会悄悄变脏。

相对 v11 改了什么

后端只有一处小修；前端字段一个没删。

位置v11v12为什么
活动的形体衬线文字流，· 分隔 一活动一胶囊，衬线字，浅底圆角 活动名里本来就有空格，· 断不干净；胶囊的边界是看出来的。
次数7 上标灰不显示 它仍决定顺序，但不再占版面。行里只剩一个字号。
+N more随文流的灰字无底色的胶囊，跟在末尾 它和活动是同一列表的成员，该站同一条基线上。
Hero 理由You added 3 new bits today Added 3 times today bits 没有对应物；times 有——你动手的次数。
Hero / More 形体字号不同，处理相同同一种胶囊，Hero 15px / More 13px 同一种东西该长一个样，只有大小之别。
new_material_count未过滤来源 加 source_type = 'material' 三个数字口径统一；对话上线不污染。

没有动：返回字段一个不删（occurrence_count 照常返回、照常排序）； 候选 5 条不变；+N 基数不变；Hero 选取与排序不变； 点击仍传分类；Start talking 仍弹 Coming soon； 暖橙只标记"今天有新东西"、整屏一处的规矩不变。
