# Poplex Logo — 需求提示词

> 用途：把这段直接贴给任何 AI（设计工具、图像生成、新的对话）来重做 logo。
> 分三部分：**A 完整版**（贴给 Claude / ChatGPT 这类会写代码出 SVG 的）、
> **B 短版**（贴给 Midjourney / 即梦 / Figma AI 这类出图的）、
> **C 待定项**（还没决定的，别让 AI 替你定）。

## A · 完整版提示词（复制以下全部内容）

```
你是一位字体设计师，不是插画师。请为一款 iOS 英语学习 App 设计 App 图标。

【产品】
名称：Poplex
做什么：用户拍照 / 录音 / 打字记录自己身边的生活，AI 把这些素材变成英语学习内容。
一句话：不是教材，不是刷题，就是你身边正在发生的事。

【要做什么】
只做 App 图标，一个字母 P。不要做字标，不要做插画，不要做吉祥物。
横版字标 Poplex 是它的伴生资产，但字标的大小写形式尚未确定，本次不做。

【必须遵守的视觉风格】
1. 底色：暖纸灰 #FBF8F5，或品牌橙 #FF7622，二选一。
2. 品牌橙固定 #FF7622，不许调亮、调暗、降饱和、加渐变。
3. 字母用高对比衬线体的骨相（Playfair / Didone 那一路），
   不要无衬线，不要圆体，不要手写体，不要像素/科技感字体。
4. 全图最多两个颜色 + 可选一个极小面积的橙色点缀。
5. 整体气质：安静、克制、有编辑感、像一本书而不是像一个学习 App。

【字形必须满足的工艺要求 —— 这是最重要的部分】
字母必须是「画出来的」，不是「拼出来的」。具体是：
- 必须是单条闭合的贝塞尔轮廓线，不许用矩形、椭圆、圆角矩形等基本图形叠加而成。
- 衬线和竖干的连接处必须有弧形托肩（bracket），不许是直角硬接。
- 笔画要有粗细变化（纵向应力：左右厚、上下薄），但最薄处不能低于最厚处的 1/2。
- 圆形部分要有 overshoot（微微超出基线和 x 高），让视觉高度一致。
- 碗（bowl）与竖干的交接要有渐变收口，不许看出「一根竖 + 一个圈」的拼接痕迹。

【明确禁止】
- 禁止任何具象物件：镜头、光圈、相机、气泡、麦克风、地球、书本、灯泡、大脑。
- 禁止把品牌橙 #FF7622 改成任何其他色值来「让它更好看」。
- 禁止渐变、投影、内阴影、玻璃质感、3D、描边发光。
- 禁止用几何基本图形拼字母。
- 禁止超过两种颜色（点缀色不算）。

【交付要求】
- 画布 1024×1024，同时验证 180 / 120 / 60 / 40 / 29 / 20 px 的显示效果。
- 29px 下任何笔画都不能断、不能糊、不能消失。
- 出三个版本：浅底版（纸底 + 墨色字）、品牌底版（橙底 + 墨色字）、深色模式版（墨底 + 纸色字）。
- 橙底版的笔画必须用深色（#2A2320），不许用白色 —— 白色配 #FF7622 对比度只有 2.45:1，会糊。
- 输出 SVG 路径代码，不要位图。

【判断标准】
放在 iPhone 桌面上，周围都是高饱和实色图标（微信绿、淘宝橙、Pinterest 红）时，
它应该因为「安静」而被注意到，而不是因为「更大声」。
```

App icon, single letter P, high-contrast serif letterform in the Didone tradition,

## C · 还没定的（别让 AI 替你决定，自己选完再改上面的提示词）

| # | 待定 | 选项 |
|---|---|---|
| 0 | **字标的大小写** | `poplex` 全小写／`Poplex` 首字母大写／`POPLEX` 全大写。你只说了「就用 poplex 做 logo」，没定形式。**这一条要先定**，因为它决定下一条。 |
| 1 | **图标用大写 P 还是小写 p** | 你原话是「就用 P」。大写更端正、方框里更平衡；小写方框里有降部死空。原则上跟字标走：字标全小写→图标用 p，字标首字母大写→图标用 P。**上面的提示词按大写 P 写的**，要改就把「一个字母 P」换成「一个小写字母 p」。 |
| 2 | **橙点留不留** | 留：品牌橙以原色出现，位置在右上角外侧。不留：全图两色，更干净。 |
| 3 | **主图标底色** | 纸底 `#FBF8F5`（和 App 第一屏同色，打开不跳变）／ 橙底 `#FF7622`（桌面上更好找）。 |
| 4 | **笔画粗细比** | 3:1 高对比（放大最贵，29px 会掉）／ 1.5:1 温和（小尺寸最稳）。 |

## D · 背景资料（怕 AI 理解偏，可以附在提示词后面）

**两张参考图的正确用法**

- **georgia 那张**：只借「全小写字标 + 其中一个字母被符号替换」这个**形式**。
  不要它的几何无衬线气质，不要那个星号造型。
- **Granola 那张**：不借它的螺旋造型。借的是它**处理主题色作图标背景**的办法——
  底色不承担识别，识别交给深色笔画；底色只要不太深也不太亮。

**已经被否掉的方案（别再出现）**

1. 「o 变成镜头光圈」——太具象、太机械。
2. 矩形 + 椭圆拼出来的 p——有硬接缝、堆砌感、生硬。
3. 一笔画的螺旋 p——方向理解错了，Granola 参考的不是造型。
4. 把 `#FF7622` 提亮成 `#F9AA76` 做图标底——品牌色不能换。

**现有设计系统色值（不要发明新色）**

| 用途 | 色值 |
|---|---|
| 品牌橙 | `#FF7622` |
| 页面底 | `#F5F0EC` |
| 卡片底 | `#FBF8F5` |
| 分割线 | `#E6DED8` |
| 标题墨 | `#2A2320` / `#3A332F` |
| 反白暖纸白 | `#FDF8F3` |
