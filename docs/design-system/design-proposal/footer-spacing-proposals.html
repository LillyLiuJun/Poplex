页脚间距与沉底比例设计方案对比 Visual Audit & Proposal

针对 Settings 版本号与 Library 品牌宣言“离卡片过近、离屏幕底部过远”的问题，按 iOS HIG 与一线出版物排版规范进行的留白重构。通过拉大上方负空间（形成心理断层）并适当收拢底部间距，让页脚沉稳扎根。

Option 0 · 当前现状
上方40 ~ 48pt
底部56pt
总沉底高度90pt

问题：上方留白仅为组间距的 1.6 倍，页脚被最后一个卡片“吸附”；离物理屏幕底部高达 90pt，悬浮在半空。

视觉比例失衡：上紧下松 (1 : 2.0)
Option 1 · 标准黄金比例 (推荐)
上方64pt
底部32pt
总沉底高度66pt

优势：上方 64pt（2.67x 组间距）彻底形成信息断层；底部收拢至 32pt（含 safeArea 66pt），真正实现“沉底稳重”。Tab2 字标恰好坐落在暖光核心。

黄金出版比例：上疏下稳 (1.9 : 1)
Option 2 · 深度呼吸方案
上方72pt
底部28pt
总沉底高度62pt

极致的大面积负空间，极具杂志印章感；适合希望页脚更低调、离操作区更远的大气风格。
