# 产品提示与反馈 · 全量清单 v1

> 盘点范围：main 分支全部 87 个 Swift 文件（扫描于 2026-08-16，main @ 2d5f739）。
> 含：Toast、Alert、Sheet、内联横幅、全屏状态页、空状态、加载状态、系统权限弹窗、触觉反馈。
> 不含：AI 学习卡内容本身（单词/例句/译文是"内容"，不是"提示"）。
> 分类约定：**正向** = 成功/庆祝；**反向** = 错误/警告/失败；**中性** = 状态信息；**引导** = 告诉用户下一步做什么。

## 一、提示的"形式"一览（全产品共 10 种）

| 形式 | 长什么样 | 打断操作？ | 消失方式 |
|---|---|---|---|
| **Toast**（AppToast 组件） | 深色胶囊 + 可选橙色图标，底部悬浮 | 否 | 自动消失：标准 4s；里程碑 2.2s；照片校验 3s |
| **撤销条**（UndoToast） | 深色胶囊 + 文案 + "Undo" 按钮 | 否 | 4 秒撤销窗口，点 Undo 立即恢复 |
| **Alert**（系统弹窗） | iOS 模态弹窗 | 是 | 手动点按钮。**全产品仅 2 处**（相机权限、删号确认） |
| **Sheet**（底部抽屉） | 半屏/全屏抽屉 | 部分 | 手动关闭（AI 同意书、翻译卡、Settings） |
| **内联横幅** | 嵌在内容流里的提示条 | 否 | 分三类：可点击重试型（点击消失）、纯提示型（持久）、常驻型（Onboarding 失败条，直到重试成功） |
| **全屏状态页**（ContentUnavailableView） | 图标+标题+说明+按钮 | 是 | 手动 Retry |
| **空状态** | 图形+标题+引导文案+CTA | 否 | 数据出现即消失 |
| **加载状态** | 骨架屏 / 动画点 / 按钮内转圈 / 文字 | 视场景 | 过程结束即消失 |
| **触觉反馈** | 振动 | 否 | 瞬时（全产品仅 4 处） |
| **系统权限弹窗** | iOS 原生弹窗 | 是 | 一次性，系统控制 |

## 四、关键发现（供产品评审参考）

1. **断网提示一族 7 处、6 种文案**，说的是同一件事，口吻各不相同（"You're offline…" / "No connection…" / "You were offline…" / "Can't connect…" / "Network unavailable…" / "Couldn't reach the server…"）。可考虑统一口径。
2. **错误文案策略统一且克制**：所有错误文案都是客户端写死的通用句，后端的技术错误详情从不展示给用户（只打日志）。唯一例外：AI 错误卡的消息可来自后端。这是符合产品调性的设计，代价是用户无法区分"我错了"和"服务器错了"。
3. **成功提示极少**：全产品明确的成功反馈只有 3 处（反馈提交 ✓、20 pops 里程碑、解锁仪式）。发送成功、生成成功、保存成功都不弹提示，靠"结果出现"确认。这是刻意的克制，但删除类操作的确认感依赖撤销条兜底。
4. **静默缺口清单**（用户可能困惑的地方）：
   - 删号失败：无任何提示（按钮重新可点，像什么都没发生）
   - 删号成功：无确认，静默关闭
   - Onboarding Continue 禁用：无解释（不知道还差什么）
   - 同意书点"Not now"：无解释，下次再弹
   - 话题词表加载失败：显示"No words in this topic yet."——把"没加载出来"说成"没有"（误导）
   - 图片加载失败：永远显示灰色占位，无重试
   - 场景详情删除：无确认、无撤销（词库有撤销，这里没有，不一致）
   - Debug 菜单"Reset Library unlock"：无确认、无成功反馈
5. **全产品只有 2 个系统 Alert**（相机权限、删号确认），零 confirmationDialog。删除一律不确认、靠 Undo 兜底——是好设计，但场景详情删除没接上撤销条，成了纯裸删。
6. **对话页失败横幅不接网络监测**：所有失败（包括断网）坍缩成同一句"Couldn't reach the server — your words are saved."，代码注释里写明断网提示本应依赖网络状态实时判断，目前未接。
7. **DEBUG 调试条在正式包可见**：对话页底部的 DEBUG 状态切换条（perm/prep/active/failed/ended/+ Line）没有用编译开关包住，正式构建里也在。
8. **死代码**：MineView 里的 ConversationStubView（"Voice practice is coming soon."）、TopicChipsRow、TranslationSheet 写了但没接线。
9. **同一句文案复制 3 份**："Couldn't update — showing saved content" 出现在 3 个文件里（两个 Tab2 页面 + 未接线的旧 VM）；"Describe this image" 出现 4 处。文案没有集中管理。
10. **Onboarding 失败条是唯一"常驻不消失"的提示**：刻意设计（网络恢复也不消失，只有重试成功才消失），防止用户以为恢复了就万事大吉。
